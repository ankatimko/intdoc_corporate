## Секция «Как это работает» (How it works)

**Eyebrow:** Процесс

**Заголовок:**
> Как это работает
> *Пять простых шагов*

### Шаг I. Загрузка документов
Перетаскиваете файлы в интерфейс или настраиваете автоматический приём из почты.

**Пример кода:**
```ts
// Загрузка через интерфейс
intdoc.upload({
  files: ['price.xlsx', 'spec.pdf'],
  source: 'manual'
})

// Или автоматически из почты
intdoc.connect({
  email: 'import@company.ru',
  autoProcess: true
})
```

### Шаг II. Парсинг нейросетью
Сервис извлекает данные из документов любого формата — Excel, PDF, сканы, письма. Поддерживаются русский, английский, китайский.

**Пример кода:**
```ts
// Извлечение данных нейросетью
intdoc.parse({
  fields: [
    'product_name',
    'price',
    'quantity',
    'delivery_time',
    'currency'
  ],
  languages: ['ru', 'en', 'zh']
})
```

### Шаг III. Сборка в единую структуру
Синонимы сопоставляются, валюты нормализуются, данные складываются в базу.

**Пример кода:**
```ts
// Нормализация данных
intdoc.normalize({
  currency: 'RUB',
  matchSynonyms: true,
  units: 'standard'
})

// База обновлена: 1,247 позиций
```

### Шаг IV. Работа с результатом
Сводная таблица, подбор лучшего варианта, ручные корректировки, сохранение истории.

**Пример кода:**
```ts
// Получение рекомендаций
intdoc.recommend({
  criteria: ['price', 'delivery'],
  limit: 3
})

// Лучший вариант: Поставщик А
// Цена: 12,500 ₽, Срок: 5 дней
```

### Шаг V. Выгрузка
Excel, PDF или готовый документ на вашем фирменном бланке.

**Пример кода:**
```ts
// Формирование документа
intdoc.export({
  format: 'pdf',
  template: 'company_letterhead',
  include: ['prices', 'logistics']
})

// Документ готов к отправке
```

**Подписи в превью документов:**
- `price_list.xlsx` (RU)
- `contract.pdf` (EN)
- `scan_001.jpg` (ZH)
- `supplier@mail`
- `+50 языков`
- `summary.xlsx` — Товар / Цена / Срок
- `1,247 записей`
- `document.pdf`

**Статус:** Готово

## Секция «Частые вопросы» (FAQ)

**Eyebrow:** FAQ

**Заголовок:** Частые вопросы

**01. Под какие отрасли подходит сервис?**
Под любые, где есть поток входящих документов с полуструктурированными данными: торговля оборудованием и комплектующими, дистрибуция, инжиниринговые компании, закупки, логистика.

**02. Что если документы поставщиков устроены очень по-разному?**
Это и есть основная задача сервиса. На этапе внедрения мы обучаем парсер работать с вашими реальными документами, а не с усреднённым шаблоном.

**03. Какие языки поддерживаются?**
Русский, английский, китайский в базовой поставке. Другие языки подключаются по запросу.

**04. Можно ли начать только с первого модуля?**
Да. Многие компании начинают с приёма и структурирования данных, а модуль формирования документов добавляют позже.

**05. Где хранятся данные?**
По умолчанию — на нашей инфраструктуре в формате SaaS. Размещение в вашем контуре возможно, обсуждается отдельно.

**06. Как оплачивается обработка нейросетью?**
По факту использования — 10 ₽ за документ. Внедрение и сопровождение оплачиваются отдельно и не зависят от объёма.
