**Канвас:** 1920×1080 (вертикальная авто-масштабируется через web component `<deck-stage>`).

**Фон слайдов:** `#f7f6f3` (мягкий бежевый).

**Шрифты:**
- `Instrument Sans` — основной текст, формы, кнопки
- `Instrument Serif` (italic + roman) — заголовки, hero, фирменные акценты
- `JetBrains Mono` — надзаголовки (eyebrows), номера шагов, бейджи, технические подписи

**Расширенная палитра акцентов** (вместо монохромного `/pitch`):

| Цвет | HEX | Семантика |
| --- | --- | --- |
| `blue` | `#2c5aa0` | Primary accent: надзаголовки, номера, нейтральные бейджи, стрелки |
| `blue-deep` | `#1f3e7e` | Для бывших чёрных блоков |
| `violet` | `#6a4f9a` | Secondary accent |
| `teal` | `#0e7c8e` | Inflation / innovation accent (мокапы, разделители) |
| `amber` | `#b87519` | Warm accent (теплый) |
| `rose` | `#b8456a` | High-impact / destructive (red marker) |
| `indigo` | `#4554a8` | Deep accent (расширение на группу) |
| `green` | `#2f8a4a` | **Зарезервирован** за «лучший вариант» в мокапах |
| `emerald` | `#149571` | Sustainability / ESG (тема слайда 8) |

**Tints** — soft-варианты каждого цвета (`*-soft`), фоны карточек.
**Deep** — насыщенные варианты для бывших чёрных блоков.
**Gradient мотивы:**
- Hero (слайд 1): radial-gradient teal+indigo фон-подсветка
- Тёмные блоки (price-block, ns.last): linear-gradient indigo-deep → teal-deep
- Hero `<em>` курсив: text-clip градиент teal → indigo

**Колонтитулы (`.meta-corner`):** мелкие мона-шрифтом справа внизу. На титуле и финале — «Конфиденциально · 2026 · v1.0», на остальных — «IntDoc AI · NN / 13».

## Слайд 2 — Проблема

**Eyebrow:** `01 · Проблема`

**Заголовок:** Как выглядит индирект-закупка сегодня

**Три карточки в ряд** (`.bignums`, цветные блоки с надзаголовком + фразой-болью + расшифровкой):

### Блок 1 — Обработка многоформатного потока *(blue)*
- **Фраза-боль:** Полный охват рынка требует **современных инструментов обработки**
- **Расшифровка:** Предложения приходят в десятках форматов, на разных языках, из разных стран. Чтобы охватить весь доступный рынок — а не только видимую его часть — нужна автоматизация извлечения и сравнения. Производительность отделов и систем здесь уже не главный фактор.

### Блок 2 — Узкий охват рынка *(violet)*
- **Фраза-боль:** В сравнение попадает лишь **часть доступного рынка**
- **Расшифровка:** Не потому что рынок узкий — в Балтии и ЕС их кратно больше. Локальные поставщики EE / LV / LT и нишевые игроки часто остаются вне таблицы.

### Блок 3 — ESG-критерии вне расчёта *(rose, акцент-tinted)*
- **Фраза-боль:** Сертификации, локальность, углеродный след — **проверяются вручную**
- **Расшифровка:** BRC, FSSC, Global GAP, Social Audit, страна происхождения — атрибуты, которые сегодня не сводятся в одну таблицу вместе с ценой и условиями.

**Визуальный паттерн карточек:** soft фон + 3px цветная top-полоса + надзаголовок мелким мона-капсом + крупная serif-фраза-боль (52px, цифра/ключевая фраза в темнее оттенке акцента) + 1px разделитель + sans-расшифровка.
